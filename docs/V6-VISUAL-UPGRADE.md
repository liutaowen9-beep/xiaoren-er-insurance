# V6.0 全站视觉版验收报告

本版本是现有 V9 功能基础上的视觉版本命名，不回退应用代码、知识库或数据库结构。沿用已有 shadcn/ui、Motion 和 Playwright 配置，没有重新初始化或安装工具链。

## 页面与设计

覆盖首页 `/`、对话 `/chat`（含知识库问答和 Agent 模式）、知识库 `/knowledge`、业务分析 `/analysis`、客户需求 `/analysis/needs`、产品对比 `/analysis/compare`、报告 `/reports`、架构 `/architecture`、设置 `/settings` 九个页面。

`src/app/visual-system.css` 提供深空蓝黑、青蓝强调、少量蓝紫渐变、玻璃卡片、统一表单和表格、状态与响应式规范。默认采用深色；已有浅深色偏好与品牌设置仍保留。新默认主色和辅助色为蓝色/紫色，用户已有自定义配色不被覆盖。

首页重塑主视觉和能力链路；知识库增加来自实际列表的文档、有效文档、切片与处理中计数；报告页统一配置与预览；工作流增加来源于实际成功工具数量的完成环和节点状态视觉。没有新增演示业务统计、工具或假进度。

## 动效与兼容

- 页面区域使用局部 Motion 淡入与小幅位移，不通过 key 重挂载业务子树，不随 token 更新重播。
- 工作流折叠/展开采用 AnimatePresence；完成环只过渡实际比例，文字始终显示真实数量。
- 悬停、按下、确认面板、消息进入使用轻量 CSS。动态连接和运行光效只由真实 running 状态触发。
- CSS 与 Motion 都处理减少动态效果偏好；首屏服务端内容可见，表单、停止按钮和流式状态不依赖动画结束回调。
- 沿用现有导航、路由、状态、聊天历史、引用、主题与品牌存储；原生危险操作确认保留。

## 数据和版本保护

本轮不修改生产知识库、文档、版本、切片、向量及密钥。生产数据和既有受保护文件通过前后SHA-256核对。截图、trace、下载样本和完整本地检查日志保存在被Git忽略的 `tmp/reports/`。

稳定快照需保留已有但未提交的知识库恢复、需求Agent和工具链必要源码；不纳入私有连接描述、数据库、上传文档、模型权重、私有报告或备份。既有稳定标签与原开发分支、stash保留，不推送远程。

## 运行与人工验收

使用现有 `pnpm build`、`pnpm start`，默认访问 `http://127.0.0.1:3002`。历史浏览器若保存了浅色主题，会继续使用浅色；可在右上角切换深色。品牌设置恢复默认会应用新的蓝紫配色，不改聊天及知识库。

已知边界：本轮没有付费DeepSeek调用，没有生产上传或写入；此前第三阶段新增的12字段真实模型质量仍需独立业务验收。没有将隔离的UI测试或规则核验冒充真实模型成功。视觉稳定标签仅标识本报告范围内的视觉与回归状态。

核心产物：`tmp/reports/visual-upgrade/` 中的桌面/移动首页、知识库、报告、需求、聊天和工作流截图；`tmp/reports/e2e/screenshot-comparison.json` 为前后比较清单。
