# 小人儿保险：独立公开源码包

本包来自当前工作区的实际文件，包含尚未提交的品牌统一、安全依赖修复和发布准备成果；没有从旧提交恢复文件，没有携带原 Git 目录或历史。独立验收日期：2026-11-17。

## 收录与排除

- 收录 Next.js 页面/API、RAG/Agent/报告/中台服务、测试、项目开发规范、启动脚本、pnpm 锁文件及空白环境模板。
- 从原工作区复制 310 个源码、配置与公开文档文件；17 份历史本地验收/诊断报告不随包分发，以免携带本机路径、运行身份或过时结论。
- 未复制任何真实 SQLite、WAL/SHM、上传原件、私有文档、切片、向量、连接登记、部署收据、浏览器记录、模型缓存、字体缓存、备份或 API 凭据。原项目中两个含历史品牌数据的本地数据库也不在本包中；没有打开或修改它们。
- 验证过程中只在本目录生成隔离测试数据。验收后移除 node_modules、构建输出、模型/字体下载物及合成运行目录；这些资源不属于源码交付物。
- README 配图来自本包的隔离 Playwright 首页截图，不包含用户资料。原验收日志保存在包外，不随包上传。

最终文件清单与 SHA-256 见根目录 `PUBLIC-SOURCE-MANIFEST.json`。它是源码核对清单，**不是数据库备份**，也不是第三方签名或独立安全认证。

## 为无历史源码包做的最小适配

1. `check:brand` 直接扫描受控源码文件，不要求 Git，也不遍历凭据和运行目录。
2. 增加 `pnpm check`、明确 pnpm 版本与公开 Embedding 下载命令。
3. Embedding 下载固定官方模型 revision，验证文件大小与上游内容哈希；中文字体仍使用已有固定哈希下载器，保留字体许可证。代理环境可使用 README 的 Node 代理命令。
4. 历史部署桥在没有 Git 对象、标签或无法核实指纹时，返回既有部署身份不匹配错误。**不放宽路径、收据、激活、模型哈希或代码指纹检查。** 本包不能接管旧库，新环境按正常流程建立空沙箱/独立知识库。
5. README 与公开技术文档不再依赖未分发的本地验收报告。

兼容性说明：环境变量、浏览器存储键、协议头、数据库标识等 `MOYU`/`moyu` 内部名称继续保留。历史中文名称仅作为转义后的只读偏好兼容别名；它们不作为当前展示品牌，不批量改写用户数据。当前展示名称为“小人儿保险”，包名为 `xiaoren-er-insurance`。

## 首次使用与限制

1. 按 README 安装依赖、配置空白模板、下载公开模型与字体，然后构建/启动。
2. 知识库、运行记录与评测记录最初为空是正常现象。上传自己有权使用的合成或公开文件后才能使用真实 RAG；没有证据时应明确资料不足。
3. 支持 Mock 的页面可以离线验证交互；DeepSeek 真实调用须由使用者自行配置和授权，可能产生费用。
4. 没有 Git 仓库时，评测代码版本显示 UNKNOWN；初始化新仓库后将记录新提交，不冒充原项目历史。
5. 需要 Node.js 服务端和持久本地目录，不能直接使用 GitHub Pages 托管后端。
6. 项目尚未声明源码开源许可证。公开前由所有者选择许可；字体、模型及其他第三方内容遵守各自许可，本包不转授私人资料使用权。
